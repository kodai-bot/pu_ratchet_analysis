 # Procedural Unit Ratchet Analysis

This repository contains the analysis code used in:

**Foley, D. (2026)**
*A Physical Definition of Technology: Motion Patterns, Selection, and the Evolution of Hominin Behaviour*

## Overview

The script reproduces the quantitative analyses reported in the paper, including:

- Cumulative procedural unit (PU) acquisition
- Linear vs exponential trajectory fitting
- Permutation test on innovation rate
- Per-assemblage complexity analysis
- Irreversibility check

## Data

The dataset used is:

Paige (2023)
https://doi.org/10.5281/zenodo.7847839

Download the dataset and place the CSV file in the same directory as the script.
